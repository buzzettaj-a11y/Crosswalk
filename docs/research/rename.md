# Renaming Crosswalk

Researched 2026-10-30. Joe asked for a name that's plain, says what the tool does, and suits a nonprofit that serves residents. Each candidate below was searched for existing software with the same or a similar name, and for unwanted meanings.

## Shortlist

| Name | Why it fits | What the search found | Watch out for |
| --- | --- | --- | --- |
| **Unduplicated** | The exact word funders and city agencies use for the number this tool produces, as in "unduplicated client count." Program staff recognize it on sight. | No software uses it as a product name. The term shows up in reporting instructions and definitions ([Law Insider](https://www.lawinsider.com/dictionary/unduplicated-client), [Austin performance reporting](https://www.austintexas.gov/sites/default/files/files/Health/Social%20Services/Performance%20Measure%20Quarterly%20Reporting%20Combined%20Instructions.pdf), [WA DSHS](https://manuals.dshs.wa.gov/sites/default/files/ESA/briefing-manual/2025Unduplicated.pdf)). | It's long, and it's an adjective. The spoken short form "Undup" sits close to UnDuplicate, a Windows duplicate-file finder ([carifred.com](https://carifred.com/unduplicate/)). |
| **Count Once** | Names the core rule. Every person is counted once overall, and once per program. | No software by that name. The nearest are generic tally-counter apps like Count This and CountMe ([alternativeto](https://alternativeto.net/software/count-this/about)). | It reads like an instruction, so "Close Count Once" is a little awkward. |
| **Unique Clients** | It's Goal 1's own name and the name of the main output file, so what the tool is matches what it produces. | No product found. It only shows up as a phrase in developer forums. | It's generic, so it's hard to search for and hard to own. |
| **People Served** | The phrase on almost every nonprofit annual report and grant report. | No product by that name. A different product called "Served" is listed on [Capterra](https://www.capterra.com/p/1222001/Served/). | It's generic. "Served" can also mean being served legal papers. |
| **Client Count** | Says exactly what it does. | No product by that name. Other case-management tools use it as a report label, like [CharityTracker](https://clienttracking.charitytracker.net/). | It reads like a column heading. It's the hardest of the five to tell apart from a feature inside another product. |

## Ruled out

| Name | Why not |
| --- | --- |
| OneCount | ONEcount is an existing customer data platform in the same space ([Capterra](https://www.capterra.com/p/173354/ONEcount/)). |
| Clean Count | M-RETS rebranded as CleanCounts, and "CLEAN COUNTS" is a filed trademark ([M-RETS](https://www.mrets.org/blog/cleancounts), [USPTO record](https://gleanmark.com/trademark/uspto-99158359)). |
| ClearCount | ClearCount is Clear Ballot's vote-counting software for elections ([Colorado SOS](https://coloradosos.gov/pubs/elections/VotingSystems/ClearVote2-3/documentation/clearCount/acceptanceTestChecklist.pdf)). |
| TrueCount | "True count" is a blackjack card-counting term, and Truecount Corporation holds trademarks ([Justia](https://trademarks.justia.com/owners/truecount-corporation-2276038)). |
| ClientRoll | It's too close to Clientrol, a CRM ([TrustRadius](https://www.trustradius.com/products/clientrol)). |
| OneList | An existing list app ([App Store](https://apps.apple.com/app/id702711062)). |
| ClientMerge, Client Roster, Unique Count, Client Tally | These are feature names inside other products (client merge in CAREWare and others, client roster in many tools, uniqueCount in New Relic), and Tally is a major accounting brand. |

## Round 2: coined names

Joe turned down round 1 because all five are common words that are likely taken. Round 2 looks for coined or compound words that are distinctive enough to own but still hint at the job. Exact-match searches turned up no software with these names.

| Name | Meaning | What the search found | Watch out for |
| --- | --- | --- | --- |
| **Wholecount** | The whole count, with everyone counted once | No product. The only hits are about whole numbers. | None found. It reads instantly. |
| **Unumera** | Latin *unus* (one) plus *numerare* (to count), so "count as one" | No hits for the word at all | People may not know how to say it (oo-NOO-mer-ah). The "Unum" start may call up Unum, the insurance company. |
| **Eachcount** | Each person counts, once | No product. The only hits are a Unity API property called ForEachCount and a lab colony counter called eCount. | None found. |
| **Countwell** | Counted right | No product. The nearest are CountThings and Countly, which are different names. | It's the least specific about what's being counted. |
| **Countfold** | Duplicates folded into one count | No software. "Count and fold" is a print-shop machine term. | It may read as printing to some people. |

Ruled out in round 2:
- Onefold has a product listing ([huntscreens](https://huntscreens.com/products/onefold)).
- Uni-Fold is a protein-folding AI model ([GitHub](https://github.com/dptech-corp/Uni-Fold)), which is the wrong association for a no-AI tool.
- Singula is taken by an agency and a Berlin company ([Clutch](https://clutch.co/profile/singula-team)).
- Uniroll reads oddly.

## Recommendation

**Round 2: Wholecount.** It keeps the plain meaning, it's a coined compound nobody's using, and it reads right in a title bar ("WHOLECOUNT"), on a button ("Close Wholecount") and on an installer. If you want the most distinctive name, go with Unumera.

**Round 1 (superseded): Unduplicated.** It's the word on the funder's own form, so nobody has to learn what the tool is for. It's serious and has no unwanted meanings, and no software uses it as a name. If it feels too long, Count Once is the friendlier second choice.

These searches aren't a trademark clearance. Before printing the name on anything for sale, a USPTO search (TESS) is worth doing.

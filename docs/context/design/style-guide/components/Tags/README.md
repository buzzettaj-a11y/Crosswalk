# Tags

Small uppercase labels that carry one of the three meanings, or a neutral fact. NEEDS YOU is solid `blue-500` with white text and is the only solid tag. A person decided is tinted `green-100` with `green-700` text and a `green-300` border. Looks wrong is tinted `amber-100` with `amber-700` text. A neutral fact (RECORDS, DOB PRESENT, proposed by the tool) is an outline in `line-2` with `ink-2` text.

A sentence-case state word in a bordered box ("decided", "confirmed by you") is used at the right of a row in place of its buttons once the decision is made. Zero radius, `tag` style, no icons inside.

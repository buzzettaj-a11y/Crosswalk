# Buttons

Four kinds, and one primary per region. Primary is `blue-500` on white text and there is one of it in any card or stage head. Secondary is white with a `line-2` border. Quiet is underlined text with no box, `blue-500` when it navigates (Preview, Open) and `ink-2` when it is a lesser action beside a primary (Accept all as they are). Held is `bg-surface` with `muted` text and a caption under it saying what releases it; it is never simply disabled without that sentence.

Height 36 to 40px, label in the `button` style, zero radius. Every button says what it does when rested on. The label names the outcome, not the mechanism: "Look up all 412", not "Run lookup".

# Two-step header

A stage that has two distinct jobs shows them as two equal cells so it is clear where you are and what remains. The active cell is white with a `blue-500` STEP kicker; the other is `bg-surface` with a muted kicker and `ink-2` title. Both show live counts in the third line, so neither step is hidden behind the other.

Used in Fix problems (step 1 the causes, step 2 row by row). Programs, which has three jobs, uses numbered section heads instead. A stage's Continue button is held until the step that gates it is done, and its caption says which.

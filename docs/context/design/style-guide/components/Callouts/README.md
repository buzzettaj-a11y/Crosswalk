# Callouts

A white card with a 3px top rule whose hue says what kind of thing it is. Needs you (`blue-500` rule, `blue-300` border) asks for a decision and holds the button that makes it. Looks wrong (`amber-500` rule, `amber-300` border, `amber-700` title) names data that does not fit and still offers a blue button to fix it, because amber marks the thing and blue marks the action. A person decided (`green-500` rule) is rare as a card and usually appears as a tag on a row instead.

The rule is always on top, never the left. Title in `row-title`, explanation in `note`, action on the right. A callout about a specific field also gives that field an `amber-300` input border so the eye lands on it.

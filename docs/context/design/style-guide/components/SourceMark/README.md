# Source mark

A 16px `ink` square with a white letter that identifies a source file everywhere it appears: Tidy up rows, the matching table list, the queue's source column, program name sources. Letters are assigned in the order files were added and stay fixed for the batch. Inside a table cell the mark is 14px.

Identity is a letter rather than a color on purpose. The three hues in this system each carry a meaning, and a per-source palette would collide with them and run out at nine tables. A letter scales, prints, and never means anything except "this file".

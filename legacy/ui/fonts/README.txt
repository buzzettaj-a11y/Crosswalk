Archivo is the design system's typeface. It is not bundled here because the
application must run fully offline and the font is not redistributed with it.

Without the files below the app falls back to the system sans stack, which
carries the same weights and keeps the layout intact.

To use Archivo, download the family (400, 600, 800) and place these files here:
  Archivo-Regular.woff2
  Archivo-SemiBold.woff2
  Archivo-ExtraBold.woff2

The stylesheet already points at them. No other change is needed.
